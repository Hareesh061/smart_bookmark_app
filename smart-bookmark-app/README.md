## 🚀 Problem Statement

Managing bookmarks across multiple tabs or devices often requires manual refreshing to see updates. 
Traditional bookmark systems do not provide real-time synchronization.

This project solves that problem by building a **Smart Bookmark Manager** that:

- Allows users to add, delete, and manage bookmarks
- Syncs bookmarks in real-time across multiple tabs
- Uses Supabase Realtime for live updates
- Provides a clean and responsive UI using Next.js and Tailwind CSS

## 🛠️ Tech Stack

- Next.js (App Router)
- Supabase (Database + Realtime)
- Tailwind CSS
- TypeScript
